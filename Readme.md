# GlobeTrotter

## Odoo Hackathon

Odoo x LDCE Hackathon — Virtual Round

## Problem Statement

GlobeTrotter — a personalized, collaborative travel planning platform where users can build multi-city itineraries, add activities to each stop, view an auto-computed budget breakdown, and (optionally) share trips publicly.
